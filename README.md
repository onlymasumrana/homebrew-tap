# Homebrew Tap

Official Homebrew Cask tap for [Twinly](https://github.com/onlymasumrana/Twinly) and other macOS apps.

## Install Twinly

```bash
brew tap onlymasumrana/tap
brew trust onlymasumrana/tap   # required on Homebrew 7+
brew install --cask twinly
```

## Upgrade Twinly

```bash
brew upgrade --cask onlymasumrana/tap/twinly
```
